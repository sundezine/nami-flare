# Nami Flare — Design Mockups

Three interactive 1970s-inspired website design directions by Sundezine:

- Golden Soul
- After Hours
- Funk & Flare

Open `index.html` in a browser. No build tools or dependencies are required.

## GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, then **main** and **/(root)**. Save.

## Content and scope

Content reviewed against https://www.namiflare.com/. Studio portrait supplied through the client’s shared Google Drive. Final media curation is pending.

The inquiry form, donations, calendar, map, and film page are design previews. The performance video embed and links to the existing store and social profiles are included. Old workshop dates and the outdated TicketSpice link are omitted.

## Editing

All three designs share the content in `index.html`. Styles are in its `<style>` block and the theme switcher and page content are in its `<script>` block. Replace `portrait.jpg` to update the shared portrait.

No Sites hosting manifest, credentials, or repository history are included. No license is granted for the client’s photography or branding.
